19AI533 Model Practical Examination 2026-27
# Aim
 To interface a digital input sensor (PIR SENSOR) with arduino
#Apparatus required
1.      Arduino Uno

2.     Bread board

3.      Tinker cad
# Procedure 

1. **Connect the PIR sensor to Arduino:**
   - VCC → **5V**
   - GND → **GND**
   - OUT → **Digital Pin 2**

2. Connect the Arduino board to the computer using a USB cable.

3. Open the **Arduino IDE**.

4. Write and upload the program to read the PIR sensor output.

5. When motion is detected, the PIR sensor gives a **HIGH** signal.

6. When no motion is detected, the sensor gives a **LOW** signal.

7. Open the **Serial Monitor** to observe the output.

8. Move your hand or body in front of the PIR sensor and check whether motion is detected.

9. Verify the output and record the result.
